# Saarthi Backlog (Deferred Features)

These features have been consciously deferred to keep Stage 1 lean, focused on trust, and maintainable by a 4-person bootstrapped team.

> **Rule:** Every release should make Saarthi more trustworthy, not more feature-rich. If a feature doesn't increase trust, reduce user effort, or improve information quality, it belongs in this backlog—not in Stage 1.
